# 🏦 Исследование факторов кредитного риска и построение ML-модели скоринга

## 📌 Описание проекта
Данный проект представляет собой разработку системы кредитного скоринга: от агрегации сырых транзакционных логов с помощью SQL до статистической проверки гипотез и построения предиктивной модели машинного обучения. 

Главная задача - выявить статистически значимые финансовые и поведенческие паттерны, отличающие надежных заемщиков от проблемных, и на их основе построить интерпретируемую модель для оценки индивидуальной вероятности дефолта.

## 💼 Бизнес-ценность
Кредитование базируется на управлении рисками. Каждый выданный кредит, уходящий в дефолт, приносит банку прямые убытки. Построение математически обоснованной модели позволяет:
1. Снизить финансовые потери за счет превентивного отсева высокорисковых клиентов.
2. Оптимизировать кредитную политику, перейдя от экспертной интуиции к Data-Driven подходу.

## 🛠 Стек технологий
* **Базы данных & SQL:** DuckDB (CTE, оконные функции, агрегации)
* **Анализ данных:** Python (Pandas, NumPy)
* **Статистика:** SciPy (Манна-Уитни, Хи-квадрат Пирсона)
* **Машинное обучение:** Scikit-Learn (Logistic Regression, StandardScaler)
* **Визуализация:** Matplotlib, Seaborn

## ⚙️ Методология и этапы работ

### 1. Сбор и агрегация данных (DuckDB / SQL)
Из сырых CSV-файлов (транзакции, клиенты, счета, кредиты) собрана единая аналитическая витрина (Data Mart). 
* Рассчитаны агрегированные метрики активности (частота транзакций, средний баланс).
* С помощью **оконных функций** выведены продвинутые маркеры риска: максимальное падение баланса (`max_balance_drop`), периоды без операций (`max_days_without_ops`), минимальный скользящий баланс (`min_rolling_balance`).
* **Архитектурное решение:** Для предотвращения утечки данных (когда последствия дефолта попадают в обучающую выборку), все транзакции жестко фильтровались по условию `date < loan_date`.

### 2. Разведочный анализ данных и статистика (EDA)
Проверены две ключевые бизнес-гипотезы с использованием непараметрических тестов (т.к. распределение финансовых метрик отлично от нормального):
* **Турбулентность баланса:** Доказано (Критерий Манна-Уитни, p-value ~ 0.001), что дисперсия баланса у ненадежных клиентов статистически значимо выше (514 млн vs 328 млн).
* **Кредитная нагрузка (DTI):** Доказана высокая предиктивная сила показателя Debt-to-Income (Тест Манна-Уитни, p-value ~ 1.17e-05) - клиенты с высокой долговой нагрузкой уходят в дефолт значительно чаще (26% против 9%).

### 3. Машинное обучение (ML)
* Проведен анализ на мультиколлинеарность (корреляции Спирмена), исключены дублирующиеся признаки.
* Данные стандартизированы с помощью `StandardScaler`.
* Учтен сильный дисбаланс классов (11% дефолтов) за счет гиперпараметра `class_weight='balanced'`.
* Обучена интерпретируемая модель `LogisticRegression`.

## 📊 Бизнес-результаты и метрики
Модель тестировалась на отложенной выборке (25%), строго очищенной от утечек данных. Результаты отражают консервативную и безопасную для бизнеса кредитную политику:

* **ROC-AUC: 0.864** - Отличная разделяющая способность алгоритма. Модель уверенно ранжирует заемщиков по уровню риска.
* **Recall (Охват рисков) = 74%** - Алгоритм успешно превентивно выявляет почти 3 из 4 потенциальных должников.
* **Precision (Точность отказов) = 31%** - Математически обоснованный компромисс. Модель настроена консервативно: банку выгоднее отказать части надежных заемщиков (пожертвовав небольшой процентной прибылью), чем пропустить дефолт и потерять выданный капитал.
* **Accuracy = 79%** - В 79% случаев итоговое решение алгоритма оказывается верным.
